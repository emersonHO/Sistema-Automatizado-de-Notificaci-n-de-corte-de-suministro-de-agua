# Guía para la persona suscriptora

1. Entra al sitio público (`https://TU_DOMINIO` o, en laboratorio, http://127.0.0.1:8000).
2. Indica un correo y un distrito de Lima Metropolitana.
3. Elige qué avisos quieres (nueva, actualización, cancelación, resumen diario opcional).
4. Acepta el aviso de privacidad.
5. Abre el correo de confirmación (caduca). Hasta entonces no hay avisos.
6. Cada aviso incluye enlaces para cambiar preferencias o cancelar. No hace falta contraseña.

Esto **no** es SEDAPAL. Un aviso por distrito **no** confirma que tu casa esté sin agua.
`ACEPTADA_SMTP` en el sistema del operador no significa que hayas leído el mensaje.
